# The seed's files

The pictures and files the seed's made-up team uses, all free to use.

| File | What it is |
| --- | --- |
| `maya.png`, `sam.png`, `priya.png`, `amara.png` | Avatars from [Open Peeps](https://www.openpeeps.com) by Pablo Stanley, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), rendered with [DiceBear](https://www.dicebear.com/styles/open-peeps/) 9.x |
| `leo.png` | An avatar from [Notionists](https://heyzoish.gumroad.com/l/notionists) by Zoish, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), rendered with [DiceBear](https://www.dicebear.com/styles/notionists/) 9.x |
| `tomas.jpg`, `sunrise.jpg` | Lakes at sunrise, drawn for the seed |
| `deploy-bot.png` | Deploy Bot's robot, drawn for the seed |
| `fernwood.svg`, `fernwood-512.png`, `fernwood-192.png` | Fernwood's fern logo, drawn for the seed, and the PNGs the browser would make of it |
| `onboarding-v3.png`, `prototype.mp4`, `prototype-poster.jpg` | A mockup of a made-up onboarding screen and a few seconds of it, rendered for the seed |
| `send-latency.png`, `send-latency.csv` | A chart of made-up numbers, and the numbers |
| `brand-guide.pdf` | A three-page brand guide, made up for the seed |

The DiceBear avatars are 256×256 PNGs from its HTTP API, 9.x, with these options:

| File | Style | Options |
| --- | --- | --- |
| `maya.png` | `open-peeps` | `seed=peep-10&backgroundColor=c0aede` |
| `sam.png` | `open-peeps` | `seed=peep-14&backgroundColor=fde68a` |
| `priya.png` | `open-peeps` | `seed=peep-3&backgroundColor=ffd5dc` |
| `amara.png` | `open-peeps` | `seed=peep-8&backgroundColor=a7f3d0` |
| `leo.png` | `notionists` | `seed=note-10&backgroundColor=bae6fd&glassesProbability=25&beardProbability=15&bodyIconProbability=0&gestureProbability=0` |

Every Open Peeps avatar also has `maskProbability=0&accessoriesProbability=15&facialHairProbability=25&face=smile,smileBig,calm,cute,lovingGrin1,smileTeethGap,explaining`.
