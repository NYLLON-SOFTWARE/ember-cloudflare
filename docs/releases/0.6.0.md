Ember 0.6 brings a new icon that's light or dark with your system, players of Ember's own for sounds and videos, Memberful members signing in with a code Ember emails them, and search that finds Chinese, Japanese and Korean words inside a sentence. Here's what's new, what updating from 0.5 does, and every pull request since 0.5.0.

## What's new

### A new icon

Ember's icon is now its flame in white on a sunset, or in the sunset's colors on near-black where your system is dark. The browser's tab shows it in each, in Chrome, Edge and Firefox, and Safari shows it light, as do a home screen and an installed app, which no browser switches yet. While a workspace has a logo, the tab shows the logo, as before.

### Messages

- Sounds play in a waveform player of Ember's own, which shows a sound's waveform before it loads, and videos in a card player, which says how long each is.
- A GIF of up to 5 MiB plays in its message, or shows its still thumbnail where reduced motion is asked for.
- Matching reactions group into one chip, which a tap joins or leaves.
- A bot's `text/markdown` posts read as Markdown, up to 12,000 characters.

### Rooms and search

- A muted room or DM is dimmed in the sidebar and never bold, and only what's for you marks it: a mention in a room, any message in a DM. A push's badge counts what Activity does.
- Search finds a Chinese, Japanese or Korean word inside a longer run of characters, and marks the words it found.

### Memberful

- Members sign in on Ember's own sign-in card with an 8-digit code Ember emails the address their Memberful account has, with **Continue with Memberful** still under the form, on a site that signs in with Memberful, has its API key and can send email.
- A code also connects the member's Memberful account to the person here with that address, where Ember proved the address theirs, and someone with an account from before can connect Memberful on their profile with a code.
- Membership's Memberful card offers **Set up email** until Ember can email the codes.

### Updates and safety

- General shows a newer beta to try beside a release to update to.
- Ember caps the table cells, referenced addresses and nesting of the Markdown it reads, so that no message can make reading it slow.

## Updating from 0.5

Your copy's Update Ember workflow offers it as a pull request, "Update Ember to v0.6.0", at its next weekly run, or now if you run it from the Actions tab. General's Ember card links to the workflow, or, for a copy without it, to adding it. Merging the pull request deploys 0.6, and the rest happens by itself:

- Each room's and the workspace's tables bring themselves up to date the first time they open, with 4 new migrations and 1 of the search index's, which add to the tables and take nothing away. The search index pairs the characters of the Chinese, Japanese and Korean messages it already holds in its hourly walk, after which search finds their words inside a run too.
- It changes no binding in `wrangler.jsonc` and needs no new secret, and Update Ember's own workflow is as it was.
- Memberful's codes wait for email: an administrator who hasn't set it up yet does so from **Set up email**, which Membership's Memberful card offers.

A copy on 0.6 beta 1 is offered this release as its next update, and releases alone from then on.
